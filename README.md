# 💎 GiftsEzz Bot

Бот с рулеткой, рефералами и выводом звёзд.

## Функции
- 🎰 Ежедневная рулетка (шанс выиграть до 10 ⭐)
- 👥 Реферальная система (+0.85 ⭐ за приглашённого)
- 💰 Вывод от 15 ⭐ (заявка админу)
- 🏆 Топ-5 лидеров
- 🔐 Подписка на канал и чат

## Запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Создайте файл `.env` с токеном
3. Запустите: `python bot.py`
