# GiftsEzz 💎

Файлы для GitHub/Render.

Функции: обязательные подписки, ежедневный кейс 3/5/10 Stars с вероятностями 50/30/20, рефералы +0.85⭐, вывод от 15⭐, уведомление админу, топ-5 за 7 дней, промокоды NEW и 10STARS, профиль, PostgreSQL.

Админ-команды: `/addchannel @channel`, `/delchannel @channel`, `/channels`.

Render Build: `pip install -r requirements.txt`
Render Start: `gunicorn app:app`

Заполни переменные из `.env.example`. Для точной проверки подписки бот должен иметь доступ к проверяемым каналам/чатам.
