# 💜 GiftHub Stars Bot

Красивый Telegram-бот в фиолетово-серой тематике с реферальной системой, ежедневной рулеткой и выводом звёзд.

Подходит для проектов в стиле Gift Hub / Stars.

## ✨ Возможности

- 🔒 Обязательная подписка на канал
- 🎁 Реферальная система (+0.85 ⭐ за каждого приглашённого)
- 📤 Кнопка «Выбрать чат» для отправки реферальной ссылки
- 🎰 Ежедневная рулетка  
  - 0.5 ⭐ — 50%  
  - 5 ⭐ — 30%  
  - 10 ⭐ — 15%  
  - 15 ⭐ — 10%
- 🏆 Топ-5 лидеров по рефералам
- 💸 Вывод звёзд (от 15 ⭐) — заявка уходит администратору
- 💬 Кнопка поддержки → @Eclipsed_consult
- 👤 Красивый профиль пользователя

## 🚀 Быстрый старт

### 1. Клонируй репозиторий
```bash
git clone https://github.com/твой_ник/gifthub-stars-bot.git
cd gifthub-stars-bot
```

### 2. Установи зависимости
```bash
pip install -r requirements.txt
```

### 3. Настрой переменные
Скопируй пример:
```bash
cp .env.example .env
```

Открой `.env` и заполни:
```env
BOT_TOKEN=токен_от_BotFather
BOT_USERNAME=имя_бота_без_@
CHANNEL_ID=@твой_канал
CHANNEL_LINK=https://t.me/твой_канал
ADMIN_ID=твой_telegram_id
```

### 4. Важно перед запуском
- Добавь бота **администратором** в канал
- В [@BotFather](https://t.me/BotFather) включи **Inline Mode** (для кнопки «Выбрать чат»)

### 5. Запуск
```bash
python bot.py
```

## ⚙️ Настройки

| Параметр          | Описание                          |
|-------------------|-----------------------------------|
| `BOT_TOKEN`       | Токен бота                        |
| `BOT_USERNAME`    | Username бота (без @)             |
| `CHANNEL_ID`      | Канал для обязательной подписки   |
| `ADMIN_ID`        | Куда приходят заявки на вывод     |
| `REFERRAL_BONUS`  | Бонус за реферала (по умолчанию 0.85) |
| `MIN_WITHDRAW`    | Минимальная сумма вывода (15)     |

## 📌 Примечания

- База данных создаётся автоматически (`bot.db`)
- Заявки на вывод приходят на `ADMIN_ID`
- Реферальная ссылка: `https://t.me/Бот?start=ref_USER_ID`
